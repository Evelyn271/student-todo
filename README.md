# 学生学习任务管理器

一个帮助学生记录和管理每日学习任务的网页应用。

## 当前功能

- 添加、编辑和删除学习任务
- 标记任务完成
- 设置高、中、低优先级
- 清除全部已完成任务
- 使用 `localStorage` 保存任务
- 按全部、未完成和已完成筛选
- 根据关键词搜索任务
- 显示任务总数和完成数量
- 响应式页面布局

## 技术栈

- HTML
- CSS
- JavaScript
- Browser Local Storage

## 运行方式

直接在浏览器中打开 `index.html`。
