# 学生学习任务管理器 🌊

一个帮助学生记录每日学习任务的网页应用，采用浅蓝色玻璃拟态设计。

## ✨ 主要亮点

- 🌅 **时间感知问候**：根据当前时间显示合适的问候语
- 💬 **每日一句**：根据日期切换激励话语
- 🎯 **完成进度环**：右上角实时显示任务完成率
- 📊 **数据统计卡片**：全部、已完成、进行中、已逾期四项统计
- 🏷️ **学科分类**：通用、编程、数学、英语、阅读、其他
- 📅 **截止日期**：支持设置截止时间，自动识别逾期
- 🎨 **优先级标签**：高、中、低三级优先级
- 🔍 **关键词搜索**：实时过滤任务标题
- 🎛️ **多维筛选**：全部、未完成、已完成、已逾期
- 📋 **灵活排序**：创建时间、截止日期、优先级、标题
- 🎨 **沉浸视觉体验**：渐变标题、波浪动画、浮动装饰、火花点缀
- 📈 **数字滚动动画**：统计数据变化时平滑滚动
- 🎉 **完成庆祝**：勾选任务时迸发彩色碎纸
- ⏱️ **番茄钟计时器**：25 分钟专注 + 5 分钟休息，含浏览器通知
- 🔁 **重复任务**：每天 / 每周 / 每月，完成后自动创建下一次
- 📥 **数据管理**：导出 JSON / CSV、导入 JSON、一键清空

- 📱 **响应式设计**：手机、平板和电脑均有良好体验

## 🎨 设计风格

- 主色调：浅蓝色（`#38bdf8` / `#0ea5e9` / `#e0f2fe`）
- 玻璃拟态卡片
- 浮动光晕背景
- 平滑动画和悬停效果
- 支持浅色 / 深色双主题

## 🛠️ 技术栈

- HTML5
- CSS3（CSS 变量、Grid、动画、`prefers-color-scheme`）
- 原生 JavaScript（无第三方依赖）
- 浏览器 LocalStorage

## 🚀 运行方式

### 方式一：本地预览

直接在浏览器中打开 `index.html`。

### 方式二：GitHub Pages 部署

1. 在 GitHub 仓库页面进入 `Settings` → `Pages`
2. Source 选择 `Deploy from a branch`
3. Branch 选择 `main`，目录选择 `/ (root)`
4. 点击 `Save`
5. 等待 1 分钟左右，访问：
   ```
   https://evelyn271.github.io/student-todo/
   ```
