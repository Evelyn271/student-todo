# 学习台 · Student Todo

一个帮助学生规划、专注和复盘学习任务的网页应用。

## ✨ 功能

- 🌅 **时间感知问候** + 📅 当前日期 + 💬 每日寄语
- 📊 **数据统计**：全部、已完成、进行中、已逾期
- 🎯 **进度条**：今日完成率带渐变动画
- 🏷️ **学科分类**：通用、编程、数学、英语、阅读、其他
- 📅 **截止日期**：自动识别“今天截止 / 已逾期 N 天”
- 🎨 **三档优先级**：低、中、高
- 🔁 **重复任务**：每天 / 每周 / 每月，自动顺延
- ⏱️ **番茄钟**：25 分钟专注 + 5 分钟休息，浏览器通知
- 🔍 **关键词搜索 + 学科筛选 + 状态筛选**
- 🎉 **勾选庆祝**：彩色碎纸撒花
- 📥 **数据管理**：JSON / CSV 导出、JSON 导入、一键清空
- 🌙 **浅色 / 深色主题**：跟随系统或手动切换
- 📱 **响应式布局**：侧栏 + 主内容（移动端折叠为单列）
- 🧭 **视图切换**：任务 / 今日 / 即将

## 🎨 设计语言

- 极光渐变背景，多层光晕浮动
- 玻璃拟态卡片，柔光阴影
- CSS 变量统一主题，浅色 / 深色双套色板
- 自定义动画：数字滚动、勾选波纹、进度条平滑过渡

## 🛠️ 技术栈

- HTML5 / CSS3 / 原生 JavaScript（无第三方依赖）
- 浏览器 LocalStorage
- Notifications API
- CSS Grid / Flexbox / CSS Variables / `backdrop-filter`

## 🚀 运行方式

### 本地预览

直接用浏览器打开 `index.html`。

### GitHub Pages 部署

1. 仓库 `Settings` → `Pages`
2. Source 选 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)`
4. 保存后等待约 1 分钟，访问：

```text
https://evelyn271.github.io/student-todo/
```

## ⌨️ 番茄钟使用

- 点击侧栏「开始」启动 25 分钟专注
- 完成后自动进入 5 分钟休息
- 浏览器会弹出通知
- 每日完成的番茄数显示在卡片下方

## 📥 数据管理

点击右上角齿轮按钮打开面板：

- **导出 JSON**：备份全部任务，可跨设备迁移
- **导出 CSV**：用 Excel / 表格软件查看
- **导入 JSON**：选择是否覆盖现有数据
- **清空所有**：一键清空，不可恢复
